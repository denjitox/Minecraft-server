# Minecraft Server — documentación de desarrollo

Repositorio liviano con la documentación necesaria para continuar el servidor de Minecraft inspirado en *Mushoku Tensei*.

## Por dónde empezar

1. `AGENTS.md`: contexto operativo, estado verificado, límites y pendientes.
2. `docs/INSTRUCCIONES/DECISIONES_2026-10-18.md`: decisiones vigentes del proyecto.
3. `docs/INSTRUCCIONES/plan_desarrollo/00_PLAN_MUSHOKUCORE.md`: plan técnico del plugin.
4. `docs/MushokuCore/DESARROLLO_2026-10-24.md`: estado reciente del desarrollo.
5. `docs/mundo/`: procedimientos, mediciones y pendientes del mundo y sus estructuras.
6. `docs/MT_Server_Base_26.2/`: instalación y configuración funcional del servidor base.

## Alcance

Este repositorio contiene texto de diseño, decisiones, procedimientos y estado técnico. No contiene mundos, backups, binarios, plugins, paquetes de entrega ni credenciales.

Las rutas mencionadas en los documentos corresponden al árbol de trabajo original y pueden no existir en este repositorio documental.

## Seguridad

Nunca agregar contraseñas, tokens, claves privadas, archivos de acceso al hosting ni configuraciones generadas con secretos. Antes de publicar cambios, revisar exactamente lo indexado por Git.
