# Descargas oficiales

Usar siempre el build más reciente disponible el día de la instalación.

## Geyser-Spigot

Página: https://geysermc.org/download/

Endpoint dinámico oficial:
https://download.geysermc.org/v2/projects/geyser/versions/latest/builds/latest/downloads/spigot

## Floodgate-Spigot

Página: https://geysermc.org/download/

Endpoint dinámico oficial:
https://download.geysermc.org/v2/projects/floodgate/versions/latest/builds/latest/downloads/spigot

## Paper

Página: https://papermc.io/downloads/paper

El objetivo actual del paquete es Paper 26.2 porque Geyser emula un cliente
Java 26.2. Revisar la página de versiones compatibles antes de instalar:
https://geysermc.org/wiki/geyser/supported-versions/

## ViaVersion

Obligatorio con el Geyser actual (ver `INSTALACION_HOSTING.md`).

Página: https://viaversion.com/

Builds oficiales:
https://ci.viaversion.com/job/ViaVersion/lastSuccessfulBuild/

Archivo validado en este paquete: `ViaVersion-5.12.2-SNAPSHOT.jar`.
