# Compatibilidad verificada al 14 de octubre de 2026

- Geyser actual: Bedrock 26.30–26.52 y Java 26.2.
- Servidor objetivo: Paper 26.2.
- ViaVersion: 5.12.2-SNAPSHOT (último build). Obligatorio con el Geyser actual:
  cubre la brecha de protocolo entre Geyser (Java 26.3) y Paper 26.2.
- Java mínimo del conjunto: 25, exigido por Paper 26.2. Geyser por sí solo
  requiere 21+, pero no reduce el requisito del servidor.
- Datapack: formato 107.1.
- Resource pack Java: formato 88.0.
- LevelledMobs: seleccionar el último build declarado compatible con 26.2.
- Skript: 2.16.2 compatible con Paper 1.21.4–26.2.
- PlaceholderAPI: 2.12.3 compatible con Paper 26.2.
- ajLeaderboards: compatible con Paper 26.2.
- Duels Optimised: build compatible con Paper 26.2.
- DecentHolograms: 2.10.1 compatible con Paper 26.2.
- TAB: 6.1.x o posterior compatible con Paper 26.2.
- LuckPerms: último build estable para Bukkit/Paper.
- Towny: 0.103.2.x o pre-release posterior que declare compatibilidad con 26.2.
- Mapeos de reliquias: formato v2 de Geyser; requieren Geyser API 2.9.3 build
  1062 o posterior y `enable-custom-content: true`.

Geyser y Bedrock cambian con frecuencia. Antes de abrir el servidor, revisar:
https://geysermc.org/wiki/geyser/supported-versions/
