# Reliquias de las Trial Chambers

El datapack escucha la primera generación del cofre de recompensa y agrega una
tirada propia sin sustituir el loot vanilla.

| Reliquia | Base vanilla | Normal | Ominosa |
| --- | --- | ---: | ---: |
| Anillo de Supresión Mágica | Amethyst Shard | 3 % | 5 % |
| Pendiente de Sara | Echo Shard | 3 % | 5 % |
| Colgante Migurd | Heart of the Sea | 3 % | 5 % |
| Espada de Paul | Iron Sword | 2 % | 5 % |
| Lanza Superd | Trident | 1 % | 4 % |
| Aqua Heartia | Diamond Sword | — | 3 % |
| Armadura Mágica | Netherite Chestplate | — | 3 % |

Probabilidad total: 12 % normal y 30 % ominosa. Los objetos son deliberadamente
bases vanilla con nombre, lore y modelo: no dependen de encantamientos propios,
mano secundaria, yunque o receta exclusiva. El pack visual puede romperse tras
una actualización, pero el objeto y su inventario continúan siendo utilizables.

La prueba se hace en un mundo descartable. Si la versión instalada cambia los
IDs de loot de las Trial Chambers, Paper lo mostrará al ejecutar `/reload`; no
se debe abrir el servidor hasta corregirlos.
