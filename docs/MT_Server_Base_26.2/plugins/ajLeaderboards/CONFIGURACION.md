# Rankings secundarios

ajLeaderboards requiere PlaceholderAPI. Se utilizará para mostrar:

- Elo de duelos.
- Muertes y victorias.
- Avances completados.
- Puntuaciones de mazmorras cuando exista el placeholder correspondiente.

El listado principal de las Siete Potencias no debe calcularse directamente
con ajLeaderboards: contiene puestos con reglas distintas y lo administra
`potencias.sk`.
