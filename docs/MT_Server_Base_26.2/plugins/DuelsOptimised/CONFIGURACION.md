# Dios de la Espada

Usar Duels Optimised únicamente para duelos oficiales sin apuestas económicas.

- Crear una arena dedicada dentro o debajo de Chaos Breaker.
- Kit idéntico para ambos jugadores.
- Desactivar apuestas de dinero y objetos.
- Activar Elo y restauración de arena.
- El jugador con mayor Elo podrá recibir el puesto 6 mediante
  `/potenciaadmin 6 NOMBRE` hasta automatizar la integración.
- Probar desconexión, muerte, empate, reinicio del servidor y devolución del
  inventario antes de habilitar desafíos por puestos.
