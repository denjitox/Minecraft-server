# Distribución subterránea controlada

Objetivo inicial para el mapa completo:

- 80–120 minas abandonadas.
- 20–30 Trial Chambers.
- 6–10 ciudades antiguas bajo las cordilleras principales.
- 40–60 mazmorras pequeñas.
- 1 fortaleza personalizada con portal al End.

No usar `generate-structures=true` después de exportar: podría introducir
estructuras superficiales y resultados incompatibles con el relieve diseñado.
Las ubicaciones se eligieron sobre el mundo exportado, comprobando altura,
bioma, cuevas, agua y distancia respecto del spawn.
